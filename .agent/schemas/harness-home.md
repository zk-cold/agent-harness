# Invariants

## Roadmap
This harness's roadmap, with backend `gh`, is its open GitHub issues, excluding those likely to fail `.agent/scripts/governance-growth`.

## Merging
Merge into this harness only branches `.agent/scripts/governance-growth <branch> <its item>` accepts.

## Approval Label
Label `approved` exactly this harness's issues holding owner-made or owner-approved requests.
